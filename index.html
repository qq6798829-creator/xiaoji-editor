导出家装包

打包带走

把已导入的墙纸、地板、家具和风格配色打成一个家装包（含清单和 SHA256）。安装时不会改动已拥有的家具、节日或限定款、存档和金币。

用「无线传输」发到设备

家装包会先下载到手机。和角色包一样：因为网页如果在 https 上，浏览器不能直接把文件发到设备的 http 地址，所以传输要由设备自己提供的上传页完成。

  1. 在设备上打开 设置 → 无线传输，屏幕会显示地址和配对码。
  2. 把屏幕上的地址填到「传到设备」页的「设备地址」，再打开设备上传页（不要用 https）。
  3. 输入 6 位配对码，选择刚才保存的家装包，开始传输。

传输步骤与角色包相同。点下方按钮可查看完整的无线传输说明。

导入

可导入角色工坊导出的压缩包，或只导入 PNG 动作文件夹并命名。旧版角色包也能打开，导出时会补上清单和 SHA256 校验。

从 PNG 文件夹新建时，请先填写名称，文件夹里至少要有正面（00）和吃饭（eat0、eat1）。

传到设备

角色包或家装包已开始下载到手机。因为本编辑器如果放在 https 网站上，浏览器不允许直接把文件发到设备的 http 地址，所以传输由设备自己提供的上传页完成。

  1. 在设备上打开 设置 → 无线传输，屏幕会显示地址和配对码。
  2. 把屏幕上的地址填到下面的「设备地址」（例如 http://10.0.0.12 或 http://xiaoji-ab12.local），不要用 https。
  3. 点「打开设备上传页」，在新标签里输入配对码，选择刚才保存的包，开始传输。
  4. 看到「安装完成」前，请不要关机或拔卡。失败会整包丢弃，原有角色、家装、存档和金币不动。

请填写设备屏幕上显示的地址，格式为 http://数字IP 或 http://名称.local。

手机请与设备使用同一家里 Wi-Fi。若还没有保存过 Wi-Fi，请先在设备设置里添加。没有可用 Wi-Fi 时，设备会改用热点，地址同样显示在屏幕上，把那个地址填进来即可。若手机提示热点无法上网，请选择继续保持连接。

若角色位已满，设备会提示先删除。若没有勾选「替换」，不会覆盖该角色已有的位置和大小配置。

关于

此编辑器与电脑版角色工坊 3.0.9 使用同一套角色包格式。可添加到主屏幕，第一次联网打开后即可离线使用。

预览里的场景背景是色块示意，不含设备或工坊里的原画，方便把本页公开发布且不附带专有素材。

源码保存在私有仓库，公开发布的只有压缩后的网页文件。浏览器仍能查看已下发的脚本。
